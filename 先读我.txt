星屿 AE 文件管理器 v9.3.2 跨电脑安装包
打包日期：2026-10-29

最快安装：
1. 将整个 ZIP 全部解压到目标电脑本地目录。
2. 保存工程并关闭所有版本的 AE。
3. 双击本目录“开始安装.cmd”。通常无需管理员权限。
4. 打开 AE → 窗口 → 扩展 → 星屿 File Manager。
5. 开启 AE 首选项“允许脚本写入文件和访问网络”。
6. 在弹窗输入一个 AI 秘钥，图片和文本共用；也可暂不设置先用素材管理。

完整图文教程：02-安装教程\完整安装与使用教程.html
功能展示图：03-功能展示图
安装器：01-Installer\install.cmd

Windows 10/11 x64，以 AE2021 为主要目标。其他支持 CEP 的 AE 版本需实机验证；不适用于 macOS/ARM64。
附带 Node 22 x64，无需 npm、数据库或部署网站后台；AI 功能需联网和有效秘钥/额度。
安装到当前用户 AppData 的 CEP 扩展目录，不安装到 AE Support Files。

此包不包含个人秘钥、生成图或用户配置。新电脑请自行填写秘钥。
