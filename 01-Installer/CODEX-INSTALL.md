# Codex 安装说明

图片和文本接口固定为 https://api.lk888.ai，用户只填秘钥，不提供地址编辑。

版本：v9.3.2-anime-20261026。表达式库置顶，AI 模块整合，一次请求三个独立可编辑方案；测试、复制、保存按钮位于各窗口下方。保留 lk888 生图修复及右上角联系信息。

请核对 INSTALL.md。先运行 install.ps1 -VerifyOnly，保存并退出 AE 后再运行 install.ps1。
安装目标是当前用户 Adobe CEP extensions/AEFileManagerAnime，适用于本机 AE2021；不覆盖原版 AEFileManager。需要完整重启 AE 加载新版。
安装器先校验清单和备份，再复制文件并移除旧功能页面。保留用户数据及秘钥配置，不读取或输出实际秘钥。
