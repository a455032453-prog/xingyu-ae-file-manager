# 星屿 File Manager v9.3.2 · 个人测试版

日期：2026-10-26。Windows x64；已识别本机 AE2021 18.2.1 / CEP10。

## 本次调整

图片和文本 API 地址均固定为 https://api.lk888.ai，不提供地址修改入口。设置页仅保留一个 AI 秘钥输入框，图片和文本共用；不展示接口地址说明。旧配置中的自定义地址读取时不再使用，原秘钥和其他配置保留；更新安装不会改写现有个人配置文件。

AI 生成表达式页面改为完整上下流程：顶部为现有表达式快捷库，支持搜索、筛选和小按钮调用，库编辑器默认折叠；下方为统一 AI 模块，描述、目标属性、模型及生成按钮集中。
点击“生成 3 个表达式”一次请求三个不同实现方案；宽屏并列三个可编辑代码窗口，窄屏纵向排列。每个窗口下方独立提供“复制”“测试 / 应用”“保存到表达式库”。测试应用到 AE 当前选中图层，可在 AE 撤销；不会自动创建测试图层或修改工程。
保存立即更新顶部库，同一结果重复保存更新该条目。生成失败保留已有结果，缺少的方案明确标注，替换未保存结果前确认，不自动重试请求。库编辑器可继续新建、维护、排序、导入导出表达式，并基于当前代码生成三个变体。

v9.2 已有功能继续保留：

仅保留三个独立页面：素材航站、AI 生成表达式、AI 生图。
素材航站采用顶部路径、文件/AE 操作分组及搜索筛选工具条；操作按钮主体高度 25px，取消右侧大按钮栏。左侧仅保留最近打开目录，支持清空和单条移除。中央素材区域扩大，选中素材后显示预览，窄窗口预览移到底部。延续星空蓝、樱花粉、薄荷绿和星屿角色插画。
三个页面右上角展示“最新版插件可以联系：uqeh3208”和“其他海量源码下载地址：www.jck123.cn”；点击网址才打开浏览器。
修复生图模型名称与请求路径。lk888 型号映射到接口实际列出的同款模型，Flare/Sunburst/Nano 在该服务走 Images API；其他服务保留原适配方式。检测失败或所选型号未列出时明确提示，不静默更换模型、不无参考图回退、不自动重试付费请求。模型列出不代表实际生成一定成功，仍以请求返回为准。
删除珍藏素材、脚本工坊、包边生图、脚本快捷工具的页面、逻辑与服务端处理入口。原“灵感实验室”合并页不再提供。

## 安装与升级

1. 解压完整 ZIP，保存工程并退出 AE，双击 `install.cmd`。
2. 打开 AE → 窗口 → 扩展 → **星屿 File Manager**。
3. 首次无配置时会弹出秘钥引导。默认接口：https://api.lk888.ai 。申请地址：https://ai.jck123.cn/ 。填写后点击“确认并使用”；也可暂不设置，先使用素材航站。

也可在解压目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\install.ps1" -VerifyOnly
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\install.ps1"
```

这是 CEP 扩展，安装到 `%APPDATA%\Adobe\CEP\extensions\AEFileManagerAnime`，由 AE2021 读取；不复制到 Support Files。附带 Node 22 x64，无需 npm。安装器验证清单哈希、先备份已有新版、清除旧页面代码，保留个人数据。安装器不会强制退出 AE。

## 秘钥与个人数据

一个共用秘钥同时用于 AI 表达式和 AI 生图，不再提供分别填写入口。接口内部统一使用 `https://api.lk888.ai/v1`，无需填写地址。
秘钥通过当前 Windows 用户 DPAPI 加密，保存在 `%APPDATA%\AEFileManager-Anime`，不写入插件源码。保存后输入框留空会保留旧秘钥；需要删除请点顶部“秘钥设置”→“清空已保存秘钥”。清空全部共用、图片和文本秘钥，后续请求需重新配置；不会撤销平台秘钥或取消已发出的请求。
分享时发送本安装包，不要附带本机用户数据目录。
升级不删除已有表达式、生图预设、参考图和生成结果。已取消模块的旧个人素材也不会被清理，但新版不再提供对应功能。

## 共存和回退

- 原开发目录、原版扩展 `AEFileManager` 与 `%APPDATA%\AE3.0` 不改动。
- v9.0/v9.1/v9.2/v9.3/v9.3.1 文件夹和 ZIP 保留，v9.3.2 单独交付。
- 安装器备份：`%APPDATA%\AEFileManagerAnime-Backups`。回退前关闭 AE，将相应备份中的 `plugin` 复制回新版扩展目录。

- 升级后请完全重启 AE；已运行的旧本地服务需退出后由面板重新启动。
